# Assets vetoriais — revisão 3

Os desenhos da versão anterior foram substituídos na composição. Os mapas usam contornos geográficos reais. Os navios são ilustrações editoriais originais, não plantas técnicas; os agrupamentos não representam quantidades operacionais reais, exceto os 24 aviões explicitamente narrados.
